# Backend Engineering Catalog — 16 Domains

1. **Backend Architecture** — service boundaries, modularity, domain separation and dependency direction.
2. **Runtime & Framework** — runtime/version, lifecycle, config, package manager and compatibility.
3. **API Engineering** — contracts, validation, pagination, versioning, errors, rate limits and idempotency.
4. **Database Engineering** — schema, relations, normalization, constraints, migrations, integrity and recovery.
5. **SQL Engineering** — safe queries, indexes, query plans, transactions, isolation, locking and performance.
6. **Authentication** — identity providers, passwords, sessions, JWT/OAuth, token lifecycle and recovery.
7. **Authorization** — RBAC/ABAC, ownership, tenant isolation and least privilege.
8. **Security Engineering** — trust boundaries, injection, CSRF/SSRF, CORS, secrets and logging.
9. **Business Logic** — domain rules, invariants, state transitions and validation.
10. **Integration Engineering** — external APIs, webhooks, queues, timeout/retry, circuit breaking and idempotency.
11. **File & Storage** — upload/download, access, validation, metadata and retention.
12. **Backend Performance** — query efficiency, caching, N+1, throughput and latency.
13. **Backend Testing** — unit, integration, contract, database, security and failure tests.
14. **Deployment & DevOps** — build, CI/CD, environments, migrations, releases and rollback.
15. **Monitoring & Observability** — logs, metrics, traces, alerting and privacy-safe diagnostics.
16. **Backend Reliability** — resilience, recovery, graceful degradation, concurrency and operations.
