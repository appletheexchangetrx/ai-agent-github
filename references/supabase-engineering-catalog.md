# Supabase Engineering Catalog — 12 Domains

Supabase optional. Repository-only evidence is valid without connection. Remote review requires user-selected project and read permissions; remote mutation needs separate approval.

1. **Supabase Architecture** — project structure, environments, client/server boundary and config.
2. **PostgreSQL Engineering** — schema, relations, types, constraints, indexes, functions, triggers and transactions.
3. **Row Level Security** — RLS enablement, CRUD policies, claims, tenant isolation and least privilege.
4. **Supabase Auth** — providers, JWT claims, sessions, redirects, lifecycle and authorization.
5. **Supabase Storage** — buckets, object paths, MIME/size constraints and access policies.
6. **Edge Functions** — Deno runtime, JWT verification, CORS, validation, secrets and errors.
7. **Supabase Realtime** — publications, channel authorization, event exposure and cleanup.
8. **Database Functions** — SQL/PLpgSQL, privileges, security definer/invoker and validation.
9. **Database Migrations** — ordering, reproducibility, schema drift, generated types, seeds and rollback.
10. **Supabase API** — PostgREST, RPC, SDK, query patterns, pagination and errors.
11. **Supabase Security** — key separation, RLS, least privilege, secrets and data exposure.
12. **Supabase Operations** — environments, logs, backups, monitoring, deployment and readiness.

Always distinguish repository evidence from connected-project evidence.
