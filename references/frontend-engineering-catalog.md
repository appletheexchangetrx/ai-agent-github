# Frontend Engineering Catalog — 14 Domains

For every domain record evidence, coverage (Reviewed/Finding/Not Verified/Not Applicable), risk and verification.

1. **Frontend Architecture** — entry points, feature boundaries, component composition, routing, layout and dependency direction.
2. **React Engineering** — components, hooks, lifecycle, state, effects, cleanup, rendering and async races.
3. **TypeScript Engineering** — strictness, type boundaries, nullability, unsafe casts and runtime validation.
4. **UI/UX Engineering** — user journeys, interaction consistency, feedback states and usability.
5. **Design System Engineering** — tokens, typography, spacing, themes, variants and reusable primitives.
6. **CSS & Styling Engineering** — CSS architecture, specificity, global leakage, maintainability and motion.
7. **Responsive Engineering** — viewport adaptation, overflow, fluid layout and touch targets.
8. **Accessibility Engineering** — semantic HTML, labels, keyboard, focus, contrast, reduced motion and assistive tech.
9. **State Management Engineering** — local/global/server state, caching, derived state, persistence and invalidation.
10. **Frontend API Integration** — contracts, validation, fetch lifecycle, cancellation, timeout, retry and errors.
11. **Frontend Security** — XSS, raw HTML, URL/redirect, token exposure, file input and client trust boundaries.
12. **Frontend Performance** — bundle/chunks, rendering, assets, caching, layout shifts and measurements.
13. **Frontend Testing** — unit, component, integration, E2E, accessibility, visual and browser tests.
14. **Frontend Deployment & Operations** — build/env config, static hosting, routing fallback, CI, source maps and readiness.

E-commerce when relevant: listing/detail, variants, gallery, search/filter, cart, wishlist, checkout, orders, profile and inventory presentation. React + Vite is initial focus, not assumption.
